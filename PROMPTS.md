# PROMPTS

Промпты, использованные при работе с ИИ над тестовым заданием Avito QA (осень 2026).

---

## Задание 1 - анализ скриншотов

Комментарий: хотел сначала получить базовые, очевидные ошибки по скриншотам (особенно влияющие на покупку и доверие), чтобы на их основе дальше дополнять список более мелкими и спорными находками.

### Базовый промпт

```text
Ты помогаешь QA-инженеру с тестовым заданием.

Контекст:
- Есть три скриншота: форма редактирования объявления, карточка продавца, карточка товара.
- Истина - только форма редактирования. Карточки сравнивай с ней.
- Нужны реальные дефекты отображения/данных, а не придирки к дизайну.
- Приоритеты из ТЗ: P0 критический, P1 высокий, P2 средний, P3 низкий.
- Пример P0 из ТЗ: не открывается объявление из выдачи.

Задача:
1. Сравни поля и блоки карточек с формой редактирования.
2. Выпиши расхождения, которые можно подтвердить по скриншотам.
3. Не выдумывай то, чего нет на скринах. Спорные места помечай отдельно как "требует уточнения".
4. Не раздувай список косметикой: сначала критичные и влияющие на покупку/доверие.

Входные файлы:
- images/edit-form.png
- images/seller-card.png
- images/item-card.png
```
